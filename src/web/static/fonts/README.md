# Roboto

The three TTF files in this folder are the Roboto weights used by the
interface:

- `Roboto-Regular.ttf` (400)
- `Roboto-Medium.ttf` (500)
- `Roboto-Bold.ttf` (700)

Source: https://fonts.google.com/specimen/Roboto

Roboto is Copyright 2011 Google Inc. and is redistributed under the Apache
License, Version 2.0. The full license text is in `LICENSE.txt` next to this
file.

The files are served by Flask from `/static/fonts/` and referenced by the
`@font-face` blocks at the top of `src/web/static/style.css`.
