# Fase D — model benchmark for the 8 GB GPU

Date: 2026-11-09

## Corpus

- 30 excerpts, 10 each from the official PT-BR editions of the Farseer trilogy
  (*O Aprendiz de Assassino*, *O Assassino do Rei*, *A Fúria do Assassino*),
  aligned paragraph-by-paragraph with the English originals.
- Alignment is monotonic and scored by shared proper nouns/numbers plus length
  ratio; low-confidence pairs are dropped. The corpus stays under
  `data/benchmark/literary/` (gitignored).
- Category mix: 7 introspection, 6 dialogue, 6 long syntax, 6 narration,
  5 description.
- Each row carries `reference_pt`, so the runner computes chrF in addition to
  the deterministic name/number/leakage/repetition metrics.

Builder: `scripts/build_aligned_corpus.py`.

## Harness

`scripts/benchmark_fase_d.py`:

- runs the installed models (`hy-mt2-7b`, `hy-mt2-7b-q6`, `index-translate-9b`,
  `qwen3-8b`);
- repeats each excerpt `--repeats` times (default 3);
- samples `nvidia-smi` memory/utilization once per second while the runner is
  active;
- aggregates chrF mean/σ, length ratio, name/number recall, leakage,
  repetition, latency p50/p95 and tokens/s;
- writes the blind review sheet and the separate A/B/C/D key;
- keeps all copyrighted outputs under `data/benchmark/` (gitignored).

Smoke command:

```bash
python scripts/benchmark_fase_d.py --models hy-mt2-7b --repeats 1 --limit 1
```

Full command, only with the GPU idle:

```bash
python scripts/benchmark_fase_d.py --repeats 3
```

## Smoke result

One aligned excerpt, Hy-MT2 7B Q4:

- chrF **0.6496** against the official PT reference.
- name recall **1.0**, English leakage **0.0**, repetition **0.0106**.
- The output caught a real gender-agreement error: the official edition has
  “Hod estava ocupada”; the model produced “Hod estava ocupado”.
- Latency was **103 s** for one excerpt, not a valid speed measurement: the
  queue was translating *Fool's Errand* at the same time and the GPU was at
  ~97% utilization.

## Blocker

A full 30 × 4 × 3 run is **360 generations**. With the active *Fool's Errand*
job on the same GPU, the run would be both slow and contaminated, and it would
starve the translation. The full matrix is therefore parked until the queue is
idle or paused; the harness and corpus are ready.
